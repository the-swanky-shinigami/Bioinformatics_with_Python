## 🚀 Repository Content
Each folder or notebook corresponds to a specific video or topic covered in the series. Inside, you'll find:
* **Interactive Notebooks (`.ipynb`):** Complete Python walkthroughs with code explanations and visualizations.
* **Sample Data:** Small-scale genomic/phenotypic datasets to test your scripts locally.

> The file names shown in the videos will match the exact file name here

### Covered Topics Include:
* Handling genomic sequences with BioPython
* Next-Generation Sequencing (NGS) Quality Control
* Explanatory data analysis (EDA) for biological data
* Working with Variant Call Format (VCF) and genomic data structures
* ...and much more!
